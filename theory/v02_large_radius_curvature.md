# V0.2 G1 — Large-radius interface and curvature expansion

## Purpose

This note derives the geometric structure needed to connect the planar interface sector to a large circular vortex without fitting the curvature term to giant-vortex data. It deliberately stops where the model-specific first-order profile response is still required.

## 1. Local coordinates around a circular interface

Let the vortex interface have radius R and introduce the signed normal coordinate

x = r - R.

For a circular wall in two spatial dimensions,

r = R + x,

d^2x = r dr dtheta = (R+x) dx dtheta.

For a collection of radial fields Phi^A(r), define a bulk-subtracted local Gibbs density

g[Phi] = g_bulk-sub[Phi].

The interfacial contribution is therefore

G_wall(R) = 2 pi int (R+x) g_R(x) dx,

where g_R is the curved-wall density expressed in the normal coordinate.

## 2. Large-R expansion

Set epsilon = 1/R and expand the curved solution about the planar interface:

Phi_R^A(x) = Phi_0^A(x) + epsilon Phi_1^A(x) + epsilon^2 Phi_2^A(x) + ...

and correspondingly

g_R(x) = g_0(x) + epsilon g_1(x) + epsilon^2 g_2(x) + ... .

Substitution into the exact circular measure gives

G_wall(R)
= 2 pi R int g_0 dx
+ 2 pi int [x g_0 + g_1] dx
+ (2 pi/R) int [x g_1 + g_2] dx
+ O(R^-2).

Define

sigma = int g_0(x) dx,

M1 = int x g_0(x) dx,

K0 = int g_1(x) dx,

K1 = int [x g_1(x) + g_2(x)] dx.

Then

G_wall(R) = 2 pi R sigma + 2 pi (M1 + K0) + (2 pi/R) K1 + O(R^-2).

This is the first important result: the planar tension sigma alone fixes only the term proportional to R. The constant and 1/R sectors require moments and/or curvature-induced profile response.

## 3. Choice of dividing surface

The coordinate R is not unique until a dividing-surface convention is fixed. Under

R -> R + delta,
x -> x - delta,

the first moment M1 changes. Therefore M1 by itself is not a physical curvature observable.

A convenient convention is the surface-of-tension gauge

M1 = int x g_0(x) dx = 0.

With that convention,

G_wall(R) = 2 pi R sigma + 2 pi K0 + (2 pi/R) K1 + O(R^-2).

Any V0.2 implementation must either impose this convention or demonstrate an explicitly invariant combination under shifts of the dividing surface.

## 4. Why the first profile correction is not an empirical fit

Let the planar Euler-Lagrange equations be

E_A[Phi_0] = 0.

Expanding the circular Euler-Lagrange equations in epsilon gives a linear inhomogeneous problem

L_AB Phi_1^B = S_A[Phi_0],

where L is the Hessian / linearized planar operator and S is generated by the geometric 1/r terms and any ensemble/boundary contributions of the radial functional.

Thus Phi_1 is determined by planar data plus a known curvature source. It is not a free giant-vortex fit function.

Schematically,

Phi_1 = L^{-1} S

after zero modes are fixed by the dividing-surface/gauge convention.

This provides the independent route required by V0.2 G1/G2.

## 5. On-shell cancellation at first variation

For a correctly bulk-subtracted functional and admissible boundary conditions, the part of int g_1 dx that is merely the first variation of the planar functional vanishes on the planar solution:

int delta g[Phi_0; Phi_1] dx = 0,

up to boundary/ensemble terms.

Therefore K0 must not be assumed nonzero from profile deformation alone. A surviving constant term has to be traced to explicit curvature, gauge, boundary, ensemble, or dividing-surface contributions.

This is exactly the unresolved point that must be derived rather than guessed.

## 6. Connection to winding number

For an n-vortex carrying quantized flux Phi_n proportional to n, a bag-like large-n configuration has area proportional to n when the interior magnetic field approaches an n-independent bulk value. Hence

pi R_n^2 B_in approximately Phi_n proportional to n,

so

R_n proportional to sqrt(n).

Consequently the interface hierarchy predicts

2 pi sigma R_n proportional to sqrt(n),

constant curvature/dividing-surface sector proportional to n^0,

and

(2 pi K1)/R_n proportional to n^-1/2.

After subtracting the bulk term and the independently computed planar perimeter term, the residual large-n scaling becomes a direct diagnostic of which curvature sector survives.

## 7. G1 scientific status

DERIVED:

- exact circular measure in normal coordinates;
- systematic 1/R organization of the wall energy;
- identification of sigma, first moment, and response sectors;
- necessity of a dividing-surface convention;
- expected mapping R_n proportional to sqrt(n) in the bag regime.

NOT YET DERIVED:

- the complete model-specific source S_A including gauge/ensemble terms;
- the invariant numerical curvature coefficient;
- whether K0 vanishes for the exact V0.1 Gibbs ensemble;
- the final coefficient converting planar response into the held-out giant-vortex prediction.

Therefore G1 remains INCOMPLETE, but the missing object is now sharply defined: derive the model-specific linear curvature source and its boundary/ensemble terms, then solve L Phi_1 = S without radial-vortex calibration.

## 8. Scientific and technological relevance if closure succeeds

### Science

1. **Vortex matter and superconductivity.** A parameter-free planar-to-curved interface map would improve analytic control of large-flux vortices and the type-I/type-II crossover near critical coupling.
2. **Topological defects.** The same asymptotic method can be adapted to interfaces surrounding strings, bubbles, domains, and other defects where curvature corrects a planar-wall approximation.
3. **Multifield phase transitions.** The neutral-scalar response provides a controlled example of how an additional order parameter modifies interfacial curvature energetics.
4. **Effective interface theory.** Separating tension, dividing-surface moments, and curvature response helps identify which coefficients are physical and which depend on coordinate convention.

### Technology

1. **Superconducting materials and devices.** Better vortex-energy estimates can contribute to models of flux penetration, vortex stability, pinning regimes, and critical-field engineering. This would be an indirect modeling contribution, not an immediate device claim.
2. **Superconducting electronics.** If the model is shown to describe an experimentally relevant material regime, improved vortex stability calculations could inform device geometries where trapped flux and vortex motion are limiting effects.
3. **Numerical design tools.** A validated asymptotic curvature formula could replace expensive full radial solves in parameter scans, reducing computational cost for large-winding configurations.

These applications are conditional on G2–G5 validation and, for material/device claims, later calibration against experimental systems.
