# Simulations

Reproducible simulation entry points belong here.

Planned first suite:

- homogeneous phase scan in `(a,b,c)`;
- mixed-mode mass extraction;
- radial vortex solver for winding `n=1,2,3`;
- grid/box convergence studies;
- two-vortex interaction-energy scan;
- three-vortex non-additivity tests.

Every run should write parameter metadata and machine-readable results under `results/`.
